# Decisions

Product decisions are recorded in the Key Decisions Log of the `{{PRODUCT_SLUG}}-docs` brain vault. Read it before planning a change.

This folder holds only repo-local ADRs: decisions about this codebase that the product vault has no reason to carry (a tooling choice, a layout rule, an exception to a rule in `.ai/rules/`).

Name each file `NNN-short-title.md` with the sections Status, Date, Context, Decision, Alternatives considered, Consequences. Number it one past the highest file already here. Never edit an accepted ADR retroactively; supersede it with a new one.

Write an ADR when "why not the obvious alternative" needed explaining during planning or review. A feature that follows existing patterns needs none.
